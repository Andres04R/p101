# p101
Este repositorio corresponde a la práctica 101 del curso de ML impartido en el Centro de Investigación en Computación del IPN.

## Encabezado

![Encabezado](Encabezado.png)

En esta práctica se exploraron las herramientas necesarias para crear y gestionar un proyecto en GitHub. Se comprendió la importancia de clonar un repositorio para poder realizar modificaciones desde el editor Visual Studio Code y posteriormente subir los cambios al repositorio remoto.

Además, se llevó a cabo un análisis exploratorio del conjunto de datos Titanic, con el objetivo de comenzar a familiarizarnos con el uso de las librerías Pandas y Seaborn para la manipulación y visualización de datos.
